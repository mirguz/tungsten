## Workspace

- Split editing into two panes, each with its own tabs and back/forward
  navigation history.
- Drag and drop to reorder notes, folders, and categories.
- Autosave while you type, with an explicit save on tab switch or close.

## Organization

- Environments drawer for switching between vaults-within-a-vault.
- Category rail with per-category emoji or image icons and accent colors.
- Folder view for browsing a category without opening every note.
- Import and export an Environment as an ordinary folder, so your notes never
  get locked into an app-specific format.

## Editing

- Rich-text editing backed by Markdown, so files stay plain text on disk.
- Image assets are cached locally for fast re-opening.

## Customization

- Light, dark, or system theme, plus a configurable accent color.
- Custom CSS per vault for anyone who wants to go further than the built-in
  themes.
