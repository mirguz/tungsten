title: Getting Started
order: 2
---

Once the app is [installed](/docs/install/) and running, pick any folder on
disk to use as your vault. Tungsten creates a `.tungsten/` subfolder inside it
for category metadata, icons, and custom CSS, and leaves the rest of the
folder untouched — see [Vault Format](/docs/vault-format/) for details.

From there:

1. Create your first **Environment** — a top-level workspace inside your
   vault.
2. Add **Categories** to it from the icon rail; each gets its own icon and
   color.
3. Create notes inside a category and start writing.
